# Customer Billing System

A simple **Customer Billing System in C** using only standard library functions (`stdio.h`, `stdlib.h`, `string.h`, `time.h`).  
This project demonstrates **file handling, structures, and menu-driven programming** in C.

---

## 📌 Features
- Add new customer accounts
- Store customer details in a file (`file.txt`)
- Search customers by **account number** or **name**
- Display customer billing details (old balance, payment, new balance)
- Simple text-based menu interface

---

## 🛠️ Technologies Used
- **Language**: C  
- **Libraries**: `stdio.h`, `stdlib.h`, `string.h`, `time.h`  
- **File Handling**: Binary file storage (`fwrite`, `fread`)
